# Ask Otto

Outdoor-gear support chat used to demo **mirrord on Amazon ECS**. A Fargate task
serves the UI, answers `/ask` from a private Postgres sidecar, and a one-line
intent bug is left in on purpose so a stolen laptop process can show the fix
without deploying.

**Live:** [https://aws-playground.metalbear.dev/ask-otto/](https://aws-playground.metalbear.dev/ask-otto/)

This folder is not [`demo-service/`](../demo-service/). Do not edit that app for
Otto, and do not point `.github/workflows/build-aws-playground-demo.yaml` at
`apps/aws-playground/**` — that workflow rebuilds `s8s-demo`.

Merging this directory does **not** deploy. The live task already exists on
cluster `s8s`. There is no Otto CI workflow yet.

## Shipped bug

`INTENT_TOPICS` in `app/main.py` maps `"return"` to `"warranty"`. Ask:

> How do I return a sleeping bag?

Otto answers with the hiking-boots warranty. The one-line fix is `"return":
"returns"`. Leave the bug in `main` so the live URL and `make local-verify` stay
aligned.

## What runs where

| Piece | Live (AWS) | Local Docker |
| --- | --- | --- |
| Chat UI + `/ask` | ECS Fargate task `ask-otto` | `ask-otto` compose service |
| Guides | Postgres sidecar on the task | `rds` on an internal network |
| Public entry | ALB path `/ask-otto/` | nginx on `127.0.0.1:8000` |
| mirrord | Remote bootstrap in the task, sessions-manager on `s8s` | not used |

The laptop cannot reach the private database. Stolen `/ask` traffic still uses
the Fargate sidecar — that is the point.

Official product docs for mirrord beyond Kubernetes (MetalBear Cloud or an
Operator on EKS) are
[here](https://metalbear.com/mirrord/docs/using-mirrord/beyond-kubernetes).
This playground spike uses the **existing standalone sessions-manager** on `s8s`,
not MetalBear Cloud and not an Operator.

## Prerequisites

- Docker with Compose
- Python 3.12 (unit tests)
- For steal against the live URL: a mirrord CLI that speaks this cluster's
  sessions-manager **Engine.IO** protocol (the 3.244.x line). Homebrew / public
  CLIs from 3.271 that talk HTTP `/assignments` return **404** against this
  sessions-manager. Do not use that failure as a reason to change
  sessions-manager, `s8s-demo`, or the ALB.

## Local stack (no AWS)

```bash
cd apps/aws-playground/ask-otto
make test
make local-up
make local-verify
```

Then open [http://127.0.0.1:8000](http://127.0.0.1:8000). `make local-verify`
checks that the ALB answers, the sleeping-bag question hits the warranty bug,
RDS sees only the task's private IP, and the laptop is locked out of Postgres.

```bash
make local-logs   # CloudWatch stand-in
make local-down   # stop and delete the local database volume
```

`local/.env` is generated by `make local-up` and is gitignored. Do not commit it.

## Steal against live Fargate

Filtered requests to the public URL are answered by your laptop. Everyone else
still hits Fargate. Postgres stays the sidecar in the Otto task.

1. Get the sessions-manager token from AWS Secrets Manager. Put it in the
   environment — **never commit it**, never print it, never paste it into git.

   ```bash
   export MIRRORD_SESSIONS_MANAGER_URL=https://session-manager.aws-playground.metalbear.dev/sm
   export MIRRORD_SESSIONS_MANAGER_AUTH_HEADER="x-mirrord-sm-auth: <token>"
   ```

2. Do **not** set `MIRRORD_OPERATOR_API_URL`. `mirrord.json` already has
   `"operator": false`. Do not set both sessions-manager and Operator URLs.

3. Do **not** run `kubectl config use-context`. This target is serverless and
   must not change the GKE playground context
   (`gke_playground-383912_us-central1-c_playground-cluster-1`). Point
   `KUBECONFIG` at an empty file for this process if you need to isolate it.

4. Run the app under mirrord from this directory:

   ```bash
   python3.12 -m venv .venv
   .venv/bin/pip install -r requirements-dev.txt
   APP_INSTANCE=laptop SEED_ON_START=false \
     mirrord exec -f mirrord.json -- \
     .venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8080
   ```

   Wait until uvicorn is listening. Do not curl `127.0.0.1:8080` for the customer
   talk track — use the public URL.

5. In the mirrord browser extension, set header
   `baggage: mirrord-session=ask-otto` with scope
   `*://aws-playground.metalbear.dev/*`.

6. Open [https://aws-playground.metalbear.dev/ask-otto/](https://aws-playground.metalbear.dev/ask-otto/)
   and ask the sleeping-bag return question. Matching traffic is stolen; other
   visitors stay on Fargate. Terminal logs print `----- stolen on laptop -----`
   and `GET /debug/last-ask` on the laptop shows the question.

If exec returns HTTP 404 from the control plane, stop. The laptop cannot pair
until the Fargate companion is checked in, and a CLI that speaks HTTP
assignments will 404 against this sessions-manager even when the companion is
fine. Do not terraform-apply `s8s-aws` to “fix” that.

## Image notes

The runtime is `python:3.12-slim-bookworm` (glibc) plus `ca-certificates`. Alpine
silently ignores `LD_PRELOAD`. Without CA certs the bootstrap cannot TLS to
sessions-manager. Live Fargate is **linux/arm64**; `local/compose.yaml` builds
**linux/amd64** for the laptop.

The bootstrap image pin used on the live task is in `versions.env`.
